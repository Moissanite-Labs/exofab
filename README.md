# Exofab

Exofab is an early proposal for a creation hub for Project Exo: a place where people and agents could collaborate to bring projects, products, and companies into the world. Its scope and implementation remain open. This direction follows the [Moissanite Labs project overview](https://github.com/Moissanite-Labs/.github/blob/main/docs/index.html).

This repository currently contains project orientation and proposals, not a runnable product. No application setup or installation steps have been established yet.

- [Orientation](docs/orientation.md) — purpose, context, and open questions
- [Roadmap and decisions](docs/roadmap.md) — proposed next steps and the current decision record
- [Contributing](CONTRIBUTING.md) — how to make a useful, reviewable contribution
- [Agent guidance](AGENTS.md) — working instructions for automated contributors
