# Contributing

Exofab is at the orientation and discovery stage. Start by reading the [orientation](docs/orientation.md) and [roadmap](docs/roadmap.md), then check existing issues and pull requests for related work.

For a proposed change, explain the problem, evidence, intended outcome, alternatives or tradeoffs, and unresolved questions. Keep changes focused and reviewable. Mark proposals as proposals and describe what was actually verified. Link public sources where helpful; do not include credentials, private material, or personal data.

No build or test commands have been established for this repository. For documentation changes, check links and accuracy. Agree the first use case and implementation direction before introducing a stack, external service, or dependency. The project's license and contribution terms have not yet been selected; do not assume a license.
